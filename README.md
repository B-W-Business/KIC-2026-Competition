# KIC Investment Assumption Watch

KIC 해외 장기 투자 메모의 핵심 가정을 기준선으로 등록하고, SEC 공시와 SEC Company Facts/FRED/UN Comtrade/SAM.gov 자료를 연결해 정량 신호와 독립적 반론을 제공하는 예선 기획 기반 MVP입니다.

## 실행

Python 3.11 이상을 준비한 뒤:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# .env의 SEC_USER_AGENT를 실제 연락처로 변경하고, 필요한 API 키 입력
streamlit run app.py
```

SEC 공개 API는 연락 가능한 User-Agent가 필요합니다. SEC Company Facts와 제출 내역에는 API 키가 필요하지 않습니다. FRED와 SAM.gov API 키는 각 기관의 키를 `.env`에 저장하세요. UN Comtrade는 공개 미리보기 API를 사용하며 사용량 제한이 적용됩니다.

## 기능

1. **투자 가정 기준선:** 기업별 메모, 지표, 공공 데이터 출처, 기준/목표값, 허용 괴리율을 SQLite에 저장합니다. 데모 기준선은 예시일 뿐 실제 KIC 포지션을 뜻하지 않습니다.
2. **SEC 공시 감지:** NVDA, AMD 등 반도체/빅테크 20개 기업의 최신 8-K/10-Q/10-K 제출 내역을 조회합니다. 수동 확인 버튼 또는 앱이 열린 동안 정기 새로고침을 사용할 수 있습니다.
3. **관련성 분류:** `OPENAI_API_KEY`가 있으면 JSON Schema 출력으로 공시와 가정의 관련성을 분류합니다. 키가 없으면 키워드 규칙을 적용하며, 이 경우 공시 본문 해석의 재현율이 제한됩니다.
4. **팩트체크:** SEC Company Facts로 매출/매출총이익률/설비투자 추이를 계산합니다. FRED는 series ID, Comtrade는 HS 코드, SAM.gov는 검색어를 입력해 관측치를 수집합니다.
5. **반론과 시각화:** 기준 목표 대비 괴리를 결정론적 코드로 계산하고, API 원자료·조회시각·한계를 구조화 리포트와 차트로 표시합니다. LangGraph 설치 시 수집과 반론 단계를 그래프로 오케스트레이션합니다.
6. **안정성:** 네트워크 오류와 rate limit에 대해 지수 백오프를 적용합니다. 자료가 없으면 중립으로 취급하지 않고 판단 보류로 표시합니다.

## 범위와 유의점

- 기준선과 리포트는 로컬 SQLite(`.kic_data/monitor.sqlite3`)에 보관됩니다. 다중 인스턴스 배포에는 공유 DB와 백그라운드 워커가 필요합니다.
- SEC 공시는 공개 텍스트를 기준선 키워드 또는 선택적 LLM 분류로 연결합니다. 자동 연결은 놓침/오탐이 있을 수 있습니다.
- 무료 외부 API의 쿼터, 지연, 회계 정의 및 통화/단위 차이가 결과에 영향을 줄 수 있습니다. 리포트는 투자 지시가 아닌 운용역 검토 보조 자료입니다.
- 격리된 임의 코드 인터프리터는 포함하지 않습니다. 수치 계산은 사전 정의된 검증 코드로 제한하여 에이전트가 작성한 코드를 실행하지 않습니다.
- SAM.gov 연동은 계약 수주 실적이 아닌 **계약 기회 공고 수**를 검색합니다. 계약 수주액을 검증하는 API가 아니며, 기업에 대한 직접 귀속도 불가능합니다.
- `OPENAI_API_KEY`는 선택 사항입니다. `SEC_USER_AGENT`는 실제 담당 연락처로 바꾸세요. 자격 증명을 저장소에 커밋하지 마세요.

## 대회 제안 대비 구현 상태

| 제안 기능 | MVP 상태 | 비고 |
|---|---|---|
| 투자 가정 기준선 등록 | 구현 | SQLite 저장, 샘플은 데모용 |
| SEC 8-K/10-Q/10-K 감지 | 구현 | 버튼/열린 페이지의 주기 폴링 |
| SEC 주장과 기준선 연관성 | 구현 | 선택적 LLM 구조화 출력, 기본 키워드 규칙 |
| SEC/FRED/Comtrade/SAM 수집 | 구현 | API별 키/입력 필요 여부 안내 |
| 수치 비교 및 차트 | 구현 | 고정 계산 코드, 자료 출처/한계 표시 |
| Red-Team 반론 리포트 | 구현 | 규칙 기반이며 LLM 투자 판단을 사용하지 않음 |
| LangGraph | 선택적 통합 | 설치 시 그래프 경로, 없으면 같은 노드 순차 실행 |
| 자동 재시도/에러 복구 | 부분 구현 | API 백오프, 임의 코드 자가 디버깅은 제외 |
| 영속 저장 | 구현 | 로컬 SQLite; 다중 인스턴스 공유 저장은 운영 확장 항목 |
| 닫힌 앱에서도 동작하는 운영 스케줄러 | 미포함 | MVP는 열려 있는 Streamlit 세션의 폴링으로 동작 |

이 상태표는 구현 범위를 정확히 공개하기 위한 것으로, 실제 공공 API 키와 네트워크 접근이 설정된 운영 환경에서 데이터 품질과 한도를 추가 점검해야 합니다.
